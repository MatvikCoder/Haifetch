# Haifetch
Экспериментальный ультралегковесный проект по типу fastfetch,  но без ASCII логотипов. Проект не является серьёзным, использовать в райсах крайне не рекомендую. Для компиляции нужен g++ (коль он есть на musl) и совсем немного времени (компиляция занимает от силы 3 секунды, а со скриптом все 5, проверено на моём железе).
# Коротко о железе, на котором компилировалось
AMD FX-6300 (6 ядер) и 4ГБ ОЗУ DDR3.
