# Haifetch
Экспериментальный ультралегковесный проект по типу fastfetch,  но без ASCII логотипов. Проект не является серьёзным, использовать в райсах крайне не рекомендую. Для компиляции нужен g++ (коль он есть на musl) и совсем немного времени (компиляция занимает от силы 3 секунды, а со скриптом все 5, проверено на моём железе).
# Коротко о железе, на котором компилировалось
AMD FX-6300 (6 ядер) и 4ГБ ОЗУ DDR3.

# EN

An experimental, ultra-lightweight project similar to fastfetch, but without ASCII logos. This is not a serious project; I strongly advise against using it in your "rices" (custom desktop setups). To compile it, you’ll need g++ (which is available on musl) and very little time—compilation takes at most 3 seconds, or 5 seconds if you use the script (tested on my own hardware).

# My hardware

AMD FX-6300 (6 cores) and 4GB RAM DDR3.
