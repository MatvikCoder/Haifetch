# Haifetch
Экспериментальный ультралегковесный проект по типу fastfetch,  но без ASCII логотипов. Проект не является серьёзным, использовать в райсах крайне не рекомендую. Для компиляции нужен g++ (коль он есть на musl) и совскемм немного времени (компиляция занимает от силы 3 секунды, а со скриптом все 8-10, проверено на моём железе).
